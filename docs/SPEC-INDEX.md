# SPEC-index — Baanschemaatje

**Status:** voorblad op branch `product/generiek`

Baanschemaatje is een **generiek product** voor elke tennisvereniging. De specificatie is gesplitst:

| Document | Inhoud |
|---|---|
| [`SPEC-core.md`](./SPEC-core.md) | Generieke regels en configureerbare parameters (KNLTB-standaard, planner-kern) |
| [`SPEC-mierlo.md`](./SPEC-mierlo.md) | Eerste clubprofiel (Mierlose T.V.) — referentie-implementatie, geen uitzondering |

Productrichting en fases: zie [`../ROADMAP.md`](../ROADMAP.md).

| [`SPEC.md`](./SPEC.md) | Operationele SPEC van de bestaande (live) stack — bewust ongewijzigd |

> Voor Baanschemaatje zijn SPEC-core + clubprofiel leidend. `SPEC.md` blijft staan zodat de live pagina en de validator/CI van `main` hun bron houden.
